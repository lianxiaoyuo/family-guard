# V5.2 多轮代码评审与验证记录

## 第一轮：服务端核心一致性与授权
- 检查令牌哈希与父子角色隔离、原子文件持久化、配对码限流、SOS 验证、重复数据去重。
- **更正**：V5.1 `withSavedFamily()` 实际只调用一次 `update()`；先前把两段重叠的终端输出误看为两次更新。此处不修改。
- 修复：SOS 断网持久化队列 + server 端 requestId 去重与迟发时间记录；启用 FG_SINGLE_FAMILY，避免共享通知主题跨家庭泄漏。

## 第二轮：定位质量与围栏
- 检查 Android GNSS、Fused、Network 来源的时间、水平精度与异常跳变校验；这些算法不能保证室内米级精度。
- 围栏 GCJ-02 转 WGS84 后进行迟滞与双定位确认；增加国内代表城市坐标转换和围栏事件测试。

## 第三轮：音视频上传稳定性
- Nginx 上传大小与 Go 服务端上限一致（26 MiB > 25 MiB）。
- 放宽最大上传读写期限，同时不在文件传输期间持有全局家庭锁；并发 SOS 不会被慢媒体上传阻塞。
- 补充模拟上传中途解绑，拒绝在解绑后完成上传授权。媒体只允许孩子端可见确认后采集。

## 第四轮：自动化测试、可部署性与安全
- Go 多轮 `go test -count=5 ./...`、`go test -race ./...`、`go vet ./...`；重新编译 Linux x64 / Windows x64 服务端。
- HTTP 路由用例验证创建家庭、配对、位置最新值、围栏进出、SOS 去重和重启、媒体上传与下载鉴权。
- `javac` 执行纯 Java 算法（31）、坐标转换（4）和 URL 安全（18）项检查。全量 Java 源码由 JDK Javac 解析器做语法检查，不是 Android SDK 编译。
- Nginx 配置与服务脚本核对，并打包完整源码及 SHA-256 逐文件清单。

## 未证明或无法保证
- Android Studio **完整编译未在此环境进行**，不存在已生成的 Android APK；用户首次打包可能遇到 SDK、Gradle 或第三方 SDK 版本问题。
- REDMI K90 与小米 10 **双机真机验收未完成**；没有长期锁屏 GNSS 精度与延迟实测数据。
- 公网 HTTPS 域名、证书、服务器通知网关及家长 ntfy 配置仍由部署环境决定；不能承诺通知必达。
- Android 关机/没电无法实时上报。摄像头、麦克风不支持隐蔽后台自动开启；要求设备端明确可见的授权采集。
