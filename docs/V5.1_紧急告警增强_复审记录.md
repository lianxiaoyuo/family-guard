# FamilyGuard V5.1 紧急提醒升级：变更与验证

## 需求范围

将 SOS 和进出电子围栏从「家长必须打开 FamilyGuard 才能看」升级为「可配置的外部 Android 通知 App 接收」，从而不要求孩子在电子围栏触发时进行任何操作。媒体拍摄、录音、录像仍是可见的设备端确认流程；不会静默远程启动 Android 摄像头或麦克风。

## 实际新增

- Go 服务端可配置 `FG_ALERT_URL`（HTTPS ntfy 主题地址）和 `FG_ALERT_TOKEN`（可选 Bearer Token）。
- 后台任务每 5 秒扫描最新 SOS / 电子围栏进出事件，发送高优先级通知；网关不可用则定期重试（事件新鲜度 6 小时）。
- 发送成功后在家庭私有 JSON 中保存通知事件 ID，重启后尽量避免重复。网络应答成功但落盘失败/意外崩溃时可能重复发送，即“至少一次”语义，不是端到端精确一次。
- 通知消息不含经纬度、姓名、家庭令牌、图片和音视频。默认需要用户在 ntfy 安装/订阅一条不可猜测的私密主题。
- Windows 提供一次性 PowerShell 初始化脚本，生成高强度私密主题并持久存放配置；Windows 局域网启动脚本能自动加载此配置。
- systemd 示例允许使用专用 `EnvironmentFile` 读取通知网关配置。
- 环境变量校验：禁止公网明文 HTTP，限制 URL 格式，私密主题路径至少 24 字符。
- 解除孩子绑定时清空相关提醒的已发送 ID。

## 代码复审与测试

1. 运行原有 Go 服务端单元测试和接口测试、`go test -race ./...`、`go vet ./...`。
2. 新增紧急消息失败重试测试：第一次网关返回 503 时不确认，第二次成功确认，重启后不再次推送。
3. 新增旧事件、非安全事件过滤测试。
4. 新增公网 HTTP、猜测性短主题、URL 带凭据和查询参数的拒绝测试。
5. 新增实际家庭配对 API → 子端 SOS → ntfy 模拟网关，以及位置上报 → 围栏离开 → ntfy 模拟网关的端到端集成测试。
6. 通过 Windows amd64 / Linux amd64 的 Go 交叉构建。
7. Android 原有纯 Java 定位、坐标参考和地址安全测试维持通过，Android 业务代码未增加依赖。

## 仍然不能保证的项目

- **没有真机安卓 APK 构建：** 此环境缺少 Android SDK 与在线 Gradle 依赖。用户 Android Studio 编译通过才能进入真机验收。
- **推送网关应答不代表手机交付成功：** 家长手机必须安装 ntfy 并允许通知，测试后台待机和跨网络实际到达情况。在中国大陆网路条件下 ntfy.sh 连通性无法保证；正式部署推荐本地可访问的自建 ntfy HTTPS 服务或小米官方 MiPush。
- **没有后台自动音视频采集：** Android 14+ 的摄像头/麦克风为 while-in-use 权限，一次安装/授权无法保证锁屏后台随时远程启动；不实现隐蔽监控。
- **手机关机/没电：** 无法继续上报位置，也无法接收通知。
- **这是附加推送功能，不改善 GNSS 本身精度。**
