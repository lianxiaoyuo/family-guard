# 上线前验收清单（只针对 2 部 Android 手机 + 1 台云服务器）

- [ ] Android Studio Gradle Sync、`assembleDebug` 完整通过；确认 app-debug.apk 确实存在。
- [ ] Linux 服务端在 127.0.0.1:8088 监听，只有 HTTPS 443 对公网开放，TLS 证书有效。
- [ ] 两部手机分别使用移动数据（关闭 Wi-Fi）访问同一个 HTTPS 域名，成功创建家庭/配对。
- [ ] 红米 K90 室外连续获取定位；小米 10 地图自动更新且显示精度/更新时间。
- [ ] 红米 K90 建筑内、商场内测试；无 GNSS 时显示正确的较大误差或过期提示。
- [ ] 锁屏 8–24 小时定位持续，自动开机恢复及断网恢复，旧位置不伪装成新位置。
- [ ] 点击孩子端 SOS 一次，家长收到；断网后点击 SOS，恢复网络后成功补发且不重复报警。
- [ ] 家长端关闭 FamilyGuard / 手机锁屏时 ntfy 能送达，记录送达时间，失败有备用联系方式。
- [ ] 电子围栏进出各触发一次，边界徘徊不会反复提醒。
- [ ] 照片、30 秒录音、30 秒录像通过 HTTPS 成功上传/下载/播放，身份错误无法读取。
- [ ] 孩子端明确确认音视频请求，采集中可见且可结束；不进行隐蔽后台采集。
- [ ] 卸载或解绑操作后旧访问凭证失效；通过恢复密钥找回家庭。
- [ ] 备份/恢复数据测试完成，服务端异常重启无数据损坏。
