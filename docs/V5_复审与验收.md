# V5 多轮审查记录与交付验收表

## 第 1 轮 — 编译错误与静态检查
- 已修复：`MainActivity.onLowMemory()` 访问修饰符 `protected` → `public`。
- 已修复：移除当前 MapLibre `UiSettings` 中不存在的 `setZoomControlsEnabled(false)`。
- 检查了 Gradle、Manifest、新增的 MediaRecorder、FileProvider 与媒体 Intent 声明。
- **APK 全工程编译尚未执行（容器没有 Android SDK/离线依赖）**。

## 第 2 轮 — 服务端权限与输入校验
- 分离家长管理围栏、孩子发送 SOS、家长发起请求、孩子拒绝或上传媒体、家长下载媒体的接口权限。
- 媒体请求种类固定为 photo/audio/video；请求 ID 必须是服务器生成的 32 位十六进制值。
- 上传大小最大 25 MiB，媒体访问需家庭令牌，媒体文件保存于受限权限目录。
- 已新增 `server/guard_test.go` 覆盖角色权限、电子围栏边缘抖动、SOS、拒绝请求、媒体上传及下载。

## 第 3 轮 — 安全守护业务
- 围栏连续两个可信点触发进出；有迟滞门槛，过期或精度差的位置不用于判断。
- SOS 可孩子端单击发送或从定位前台通知触发；SOS 网络通道独立于位置上传。
- 预先设置后位置与围栏无需每次再点，但音视频仍由设备前台明确启动，不能暗中启动。
- SOS 写入服务端事件，不等于家长手机已经收到通知：**尚未接入厂商推送**。

## 第 4 轮 — 数据生命周期与异常处理
- 媒体仅保留至多 24 小时访问权限，并定期清理磁盘文件，包括因元数据裁剪而遗留的旧文件。
- Go 的保存操作以持久化成功为提交条件，写盘失败返回错误。
- 对位置数据拒绝过期、越界值、无效提供者和不合法坐标系。

## 第 5 轮 — 可执行回归
- Go `go test ./...`、`go test -race ./...`、`go vet ./...`。
- javac 纯 Java 定位策略、坐标转换和服务器地址测试。
- Windows/Linux Go 交叉编译，Linux 实际 HTTP 健康检查和权限接口冒烟。
- ZIP 归档读取和 SHA-256 文件列表完整性校验。
