# FamilyGuard V4 真机验收清单

- [ ] Android Studio Gradle Sync 成功、Build APK 成功，APK 可安装到小米 10 和 REDMI K90。
- [ ] Android 高德 SDK Key 与 `com.familyguard.app`、当前调试签名 SHA1 匹配；用户确认第三方 SDK 隐私说明。
- [ ] 两台手机同服务器、家庭配对成功；未配对的设备无法查询或提交坐标。
- [ ] REDMI K90 开启共享后通知栏有显式状态、能点停止；点击停止后不再产生新的坐标。
- [ ] 开阔天空站立 3 分钟，记录真实地标位置与屏幕显示位置的测量距离；测量绝对误差，而不只是看“±X 米”。
- [ ] 沿直线路段步行 5 分钟，家长地图标记移动，位置时间戳更新，核对点位不会因为 WGS84/GCJ02 转换产生几百米偏移。
- [ ] 在楼宇、商场内测量：验证高德融合备用是否有新坐标，若无定位则明确显示位置过期。
- [ ] 锁屏 30 分钟、1 小时：查看是否还持续上传；适配澎湃 OS 位置权限和电池限制。
- [ ] 关闭孩子端网络 60 秒、再恢复：只上传最新缓存点，不“回放”错误的历史路径。
- [ ] 关闭孩子手机：家长端能看到最新缓存位置和过期时间，但**不应显示仍在实时定位**。
- [ ] 伪造/非法 `coordType` 不能上传；角色令牌不得互换，HTTPS 校验不可被绕过。

## 重要限制

此项目只使用手机内置 GPS/北斗/Galileo、Wi-Fi、基站及高德融合能力，没有专用 RTK 硬件和差分数据。只能尽量获得更准确、更及时的定位，不保证厘米级，也不能在彻底断电后继续定位。定位误差半径是系统估计，误差可能比展示数字更大。
