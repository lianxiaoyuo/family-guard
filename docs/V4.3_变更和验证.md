# V4.3 核心功能改造记录

## 代码范围

- `TrackingService.java`: 独立执行器，缓解弱网定位线程阻塞；上传前检查 60 秒时效；GnssStatus 诊断。
- `LocationQueue.java`: 并行存取时同步队列方法，保留本地最新点的加密缓存策略。
- `GnssDiagnostics.java`: Android 原生卫星状态、C/N0，非精度提升算法。
- `MainActivity.java`: 原生 MapLibre + OpenFreeMap 线上底图，实时 marker + 位置精度圈；删除对高德 Key 的地图强依赖。
- `CoordinateReference.java`: 可选 GCJ-02 与 WGS84 转换。主定位坐标仍是 WGS84。
- `Api.java`: 定位/轮询请求短超时，账户请求保留原超时。
- `server/main.go`: 诊断字段验证及返回，不改变配对鉴权。

## 验证

- Go: `go test ./...`, `go test -race ./...`, `go vet ./...`
- 纯 Java: `AccuracyPolicySelfTest`, `CoordinateReferenceSelfTest`

## 功能验收建议

1. 室外无遮挡处静止测试 10 分钟，对比手机系统定位，记录实际偏差、精度半径及卫星数量。
2. 步行 500 米，验证标记每秒有新坐标时跟随，停止后不会出现不合理“瞬移”。
3. 手机切换 Wi-Fi/4G、关闭/恢复网络，验证后台采集与恢复上传最新位置。
4. 手机锁屏 30 分钟，检查通知栏、位置更新时间、是否被系统后台策略终止。
5. 断开 OpenFreeMap 网络，验证地图可能空白但最新经纬度依然刷新；不要把地图网络错误误认为 GPS 失效。
6. 点击停止共享，确认家长端不再收到新位置且旧坐标显示为过期。

## 无法消除的限制

- 手机断电/关机无法持续上报；Wi-Fi/基站的室内精度强依赖系统数据。
- 公开第三方瓦片服务无中国大陆稳定服务保证；真正要控制底图可用性可将 MapLibre 指向自托管合规地图。
- 不提供未经对方设备明确授权的隐蔽追踪能力。
