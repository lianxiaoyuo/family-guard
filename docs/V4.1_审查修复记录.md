# FamilyGuard V4.1 代码复核与修复记录

检查来源：V4 原始完整 ZIP，逐文件核对并在此基础上修复。V4.1 为 Android Studio 全量源码，不用叠加安装 V4。

## 本次确定性修复

1. `AndroidManifest.xml` 补齐 `ACCESS_WIFI_STATE` 与 `CHANGE_WIFI_STATE`，以满足高德 Wi-Fi/基站融合定位的配置要求。
2. `MainActivity.java`：拒绝第三方高德 SDK 授权时，仍能启动 Android 原生 GNSS；可通过单独按钮再次启用高德。
3. `TrackingService.java`：跨 WGS84/GCJ-02 定位来源先用高德 GPS 坐标转换，再执行跳变判断；转换不可用时不进行错误的跨系直比。
4. 修复原 ZIP 中 4 个中文脚本文件名二次编码产生的乱码，保持 README 中的文件名可以找到。
5. 更新 Android 客户端版本为 `4.1.0` / versionCode 5。

## 尚未验证的关键事实

- 没有 Android SDK 35：未执行 `assembleDebug`，不能保证 APK 能一次编译成功。
- 未安装到 REDMI K90 与小米 10：高德 SDK 启动、实际 GNSS 精度、锁屏持续定位、系统后台限制均未真机验证。
- 即使软件无错误，单次显示 ±3 米只是 SDK 的误差估计，不保证真实误差恒为 3 米。
- 手机彻底没电/关机后不能继续实时定位，只能显示最后成功上传的位置。

## 强制验收顺序

1. 用 Android Studio、JDK 17 与 SDK 35 完成 `assembleDebug`；若失败，以第一条真实编译错误为准，不得把语法解析通过说成编译通过。
2. 两台手机使用相同服务端、安装 APK。孩子端在不开启高德授权时检查原生 GNSS 可追踪。
3. 在孩子端启用高德 SDK，再检查室内辅助定位和坐标源切换时地图无明显跳变。
4. 开阔室外不同已知点连续定位，统计真实距离误差的中位数和 95 分位，而非仅显示 SDK 的 accuracy 值。
5. 锁屏 1 小时、掉线与恢复、APP 切前后台各验证最新位置的真实时间戳。

**结论：** 这是经静态复核和可执行服务端/定位策略测试的 V4.1 修复源码，不是实测合格的生产 APK，也不宣称零 Bug。
